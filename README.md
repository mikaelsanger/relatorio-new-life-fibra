# Relatório Setor de Marketing — New Life Fibra

Dashboard de resultados de marketing (Meta Ads, vendas gerais e tráfego pago), de janeiro a outubro de 2026.

- `index.html`: o dashboard completo, em um único arquivo. Abra no navegador.
- Fonte das campanhas: exportações do Gerenciador de Anúncios do Meta. Vendas, instalados e vendas pagas informados pela empresa.

Sistema desenvolvido por MS Think Different.
